# CLI based number guessing game

It is a CLI based number guessing game.

The application asks the computer to generate a random number and the user tries to guess it.

## How to run the project

> On some operating systems like macOS or linux you may need to use python3 or pip3 instead of python or pip

run the following command in the terminal - *python guess_number.py*

It should start the game, follow the on-screen instructions.

**Important Note -** Don't forget to have fun :)
